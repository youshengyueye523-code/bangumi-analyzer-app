# Bangumi Analyzer Companion 用户指南

**Bangumi Analyzer Companion** 是 Bangumi Analyzer 的 Windows 独立桌面伴侣与生命周期管理器，内置原创站娘「小番（Xiaofan）」陪伴舞台与安全隔离的本地运行架构。

## 1. 核心设计原则

- **数据只存本机**：Bangumi 收藏数据库（`bangumi.db`）和个人设置（`config.json`）均保存在你选择的安装目录 `data/` 文件夹下。
- **凭据最小暴露**：Bangumi Access Token 与 AI API Key **不会** 写入 Companion 的偏好文件或渲染层 `localStorage`，仅经可信 IPC 直接写入本地 Analyzer 的 `data/config.json`。
- **绝不强杀或污染全局环境**：仅管理由 Companion 安装和启动的受管实例；默认仅绑定本机回环地址 `127.0.0.1` 的随机隔离端口（绝不占用 `8787` 端口）。

## 2. 安装与首次向导 (M2)

1. 图形安装版请双击 **`Bangumi-Analyzer-Companion-Setup-2.0.0-win-x64.exe`** 按向导安装；便携版请解压 `Bangumi-Analyzer-Companion-Portable-2.0.0-win-x64.zip` 后运行目录中的 **`Bangumi-Analyzer-Companion.exe`**（另保留 **`Start-Companion.vbs`** / **`Start-Companion.bat`** 备用脚本）。
2. **环境检查**：真实核验 Windows x64 系统架构、随附 Analyzer `v2.0.0 r5` ZIP 包 SHA-256 完整性、目标磁盘可用空间、写权限、回环端口可用性与 Bangumi API 连通性。
3. **选择安装目录**：
   - 支持系统原生文件夹选择框与实时安全校验。
   - **安全限制**：禁止安装到 `Program Files`、`Windows`、OneDrive/网盘同步目录以及网络 UNC 路径，防止 SQLite 数据库损坏或权限锁死。
4. **Bangumi 账号与 AI（均支持跳过）**：
   - 可输入 Bangumi 用户名或数字 UID（及可选个人令牌同步私有收藏）并即时联机核验。
   - 如暂不配置或离线环境，可先点击「稍后再绑定」完成本地安装。
5. **自动解包、建库与首次同步**：
   - 对安装包执行 SHA-256 校验并解包，启动本地 Analyzer 写入配置并可选拉取收藏进度（支持实时中断与稍后补全）。
6. 首次引导完成后，再次启动 Companion 将直接进入日常启动动画或主面板。

## 3. 日常使用与窗口控制 (M1-B)

- **无边框桌面窗口**：顶部标题栏支持拖拽、最小化、最大化/还原与安全关闭（关闭窗口前会确认 Analyzer 服务与数据库已安全落盘退出）。
- **全屏沉浸模式**：按 **`F11`** 或点击标题栏全屏图标可进入/退出无边框全屏；按 **`Esc`** 退出全屏。
- **快捷键、主题与页面快捷入口**：
  - 主页「档案与快捷入口」提供六个直达路由卡片：**仪表盘** (`/`), **收藏库** (`/library`), **统计分析** (`/analysis`), **系列 / IP** (`/series`), **我的画像** (`/profile`), **数据中枢** (`/diagnostics`)，兼容每次启动的随机本机端口。
  - 主页按 **`R`** 刷新实时运行状态；
  - 在「启动与偏好」中可独立设置 **Companion 桌面主题** 与 **Analyzer 网页端主题**（深色 / 浅色 / 跟随系统，持久化于本机 `data/config.json` 并与网页端双向同步），以及开启/关闭「启动时自动启动 Analyzer」「服务就绪后自动打开网页端」（每次启动仅触发一次）、小番舞台、提示音效或减弱演出动画；
  - Windows 双显卡/核显环境默认使用高兼容 ANGLE D3D11 渲染路径并支持崩溃自动安全回退 2D 舞台，也可在偏好中切换 GPU 模式（重启生效）。
  - **注意**：在浏览器中关闭 Analyzer 网页标签页不会停止后端服务，需点击主控卡的「安全停止」或关闭 Companion 主窗口安全停机。

## 4. 备份、自检、安全更新与卸载 (M3)

在主页切换至 **「维护与诊断」** 标签页即可使用全部维护能力：

- **数据库备份与安全回滚**：
  - 点击「立即备份」生成带有时间戳的 SQLite 快照。
  - 执行「恢复」时必须经过二次确认；Companion 会 **先自动创建恢复前现状快照**，再安全停止服务、覆盖恢复并完成校验。
- **全量完整性自检与脱敏诊断导出**：
  - 一键核对程序核心清单（SHA-256）、`PRAGMA integrity_check` 数据库完整性与配置状态。
  - 「导出诊断」生成的 JSON 报告自动剥离敏感凭据与私人路径。
- **安全更新与失败自动回滚**：
  - 选择本地 `.zip` 更新包或更新清单 `.json` 后执行更新；更新前自动备份 `data/` 并快照旧版程序文件，仅替换程序本身（**绝不覆盖 `data/`**）。
  - 若新包解包失败、SHA-256 校验不通过或启动 `/api/health` 失败，将 **自动回滚** 至上一可用版本与数据快照。
- **安全卸载（默认保护数据）**：
  - 默认选项仅移除程序文件与桌面快捷方式，**完整保留你的 `data/` 数据库与历史备份**。仅当显式勾选并二次确认删除数据时才会清理 `data/`。
