# 时间趋势：数据与范围契约

本功能采用“当前范围趋势＋可选全历史概览＋统一精读范围＋精确明细”。默认按月，使用上海日历的当前月及此前11个月；顶部主图实际只接收此范围的逐期数据并据此建立坐标轴，不是在全历史图上高亮。全历史概览默认收起，展开/收起不改变范围；“全部历史”仍是独立的精读范围快捷操作。“最近有记录”是主动选择，不自动代替近期空范围。产品版本号和正式运行产物的交付另行安排。

## 数据身份

`GET /api/stats/timeline` 保留原字段及含义：`added` 是按收藏最后更新时间分桶的当前收藏数，`updated` 是该桶中当前为看过的条目数，`total` 是完整归集序列的前缀和，`episodes` 使用既有 canonical 集数/进度规则，`averageRate` 使用既有有效评分及 null 规则。它们都不是精确的历史新增、完成或观看事件。

新增字段全部可选，以兼容旧服务与旧 Web：

| 字段 | 定义与消费者 |
| --- | --- |
| point.ratingSample.ratedCount | 当期 canonical 有效评分收藏数；明细、Tooltip和范围均分使用 |
| point.ratingSample.ratingSum | 同一批有效评分的未舍入总和；范围均分为总和/样本数，不平均周期均分 |
| context.contextVersion | 当前为1；客户端仅识别已支持的上下文版本 |
| context.visibility / dataVersion | 本次聚合的同一可见性与数据版本；完整性证明和页面口径门禁使用 |
| context.sequence | kind=full；complete=true表示当前响应覆盖源最小至最大周期的完整闭区间，from/to为源端点；空源均为null |
| context.timeCoverage | datedCollections为非空日期且成功归桶的当前收藏数；undatedCollections为NULL/空日期收藏数；不代表历史事件覆盖率 |
| context.viewReferenceAt / referenceMonth / calendarZone | 本次读取时间、当前日历月、Asia/Shanghai；用于日历投影、未结束周期提示及读取上下文 |
| context.sourceRefreshedAt | 已有可靠同步完成时间或null；页面显示来源同步信息，不用MAX(updated_at)冒充来源刷新时间 |

完整性针对**聚合周期**，不扩大既有SQL字符串分桶为完整timestamp验证。非法聚合周期继续显式失败，不返回成功的部分序列。P0-A完整周期生成器保持不变。

评分样本确知为0时，sum=0、count=0，均分为null；缺失字段表示未提供，不能补0或从舍入均分倒推。未新增来源无法证明的集数覆盖分类。

服务端聚合仍按dataVersion和visibility缓存，但读取时间、日历月和来源刷新时间在每次读取时更新。Web每分钟及窗口重新聚焦时重新读取时间上下文。日历投影只发生在新Web，不改变旧API points端点；只有完整性证明、连续键、数量与前缀一致时，才为源外日历空期生成0，累计保留源前缀。

## 统一范围

URL参数：`tg=month|quarter|year`，`tr=recent|recorded|all|custom`；custom使用包含边界的`from=YYYY-MM&to=YYYY-MM`。省略参数为month/recent。写入只处理上述参数，保留其他标签页/筛选参数。提交范围进入浏览历史，刷新和返回可恢复。

- recent：当前日历锚定最近12期。recorded：以源末期为终点的最近12期，仅用户主动选择。all：完整源历史至当前日历/源末期中的较晚者。
- 粒度切换保留绝对月份意图，按新粒度包含边界所在的整个年/季；all保留全历史意图。精读标题展示实际包含的周期；重新选择“最近12期”才按当前粒度重新计算12期。
- 常驻DOM导航使用分行端点和独立的整段平移区域。拖动同步预览日期与顶部主图，最多每动画帧更新一次，仅使用已加载序列；草稿状态局限于顶部图与控制区，不重新请求序列或重算下方摘要/明细。松手一次提交；Esc、pointercancel或失去捕获取消，主图恢复已提交范围，待处理的预览帧也取消。整段平移保留跨度并夹取历史边界；键盘端点/平移在按键释放时提交。数据版本、口径或范围变化时取消旧手势。日期弹窗仍编辑独立draft，只有“应用范围”才提交；取消、关闭或Esc不改变已提交状态，焦点返回开启者。
- 非法、倒序、数据恢复后已越界的固定范围保留URL意图并要求主动重选，不静默clamp为另一段历史。
- 同一个已提交范围控制数量图、独立0–10评分图、集数图、范围摘要、累计深入查看及明细。可选概览打开时保持源全历史，保留Tooltip、稀疏基线点和点击定位；最多160柱，明确提示每柱求和合并数。顶部主图逐期展示所选范围，刻度抽稀只影响文字，不合并或修改数据；ECharts实例在拖动更新时复用。精读与累计不据此改变原粒度或全历史前缀基数。
- 单期数据的单期精读不显示无效前后导航/滑块。默认近期日历可包含已知零期；它与“只有一个有记录周期”是不同概念。
- 明细每页50期，有直接页码定位，全部历史可达。图表仍使用整个精读范围；表格分页只控制渲染，不改变范围摘要。

累计曲线默认折叠，打开/关闭不改变范围，范围起点不重置前缀。极值可以定位为单期；小值比较明确筛选低于峰值的最小12个非零周期，使用局部线性尺度，主图和原数值保持不变。

## 兼容与异常

旧Web继续读取原字段。新Web连接旧Server时显示“完整性未确认”的兼容视图，仅访问已返回周期，不能将末个返回周期称为最新记录，不能推断全历史或在尾部补0；样本缺失时范围均分显示未提供。恰好601期不能作为完整性证明。

完整新响应分开显示：无收藏、全部收藏无日期、已知日历零期。读取失败使用既有错误状态和重试；不伪装为空数据。完整性信息自相矛盾时停止精读展示。同一响应计算各部分，不拼接不同快照的结果；新响应口径与当前配置不一致时重新读取。

本次开发者测试和真实浏览器证据不构成独立终验PASS。真实触屏、不同设备与持续压力仍应在综合验收中单独记录。

## 时间坐标与可见刻度

时间图统一使用原始 `period` 键作为类目身份，series 与 Tooltip 按同一个数据索引读取；轴文字独立格式化为 `YYYY-MM`、`YYYY Q1～Q4`、`YYYY`。不靠改文字补偿坐标偏移。

主图、可选概览与下方数量/评分/集数/累计图共用基于真实11px字体测量的布局：标签居中于对应类目坐标，按端点文字半宽和Y轴文字预留真实边界；柱图使用类目带中心，折线使用端点坐标。禁止首标签left/末标签right造成的视觉中心偏移。

标签密度由可用绘图区、实际字宽与间距计算，不按固定期数隐藏。优先全显，放不下时使用日历锚定的易读规则间隔；保留首尾，跳过与端点相撞的邻近格。关闭ECharts第二次自动隐藏，避免已抽稀集合再次无规则缺失。resize时重新测量宽度，不重新创建ECharts实例。抽稀只影响文字，全部数据与累计前缀仍保留。

概览合并柱明确标注完整起止区间，文字中心对应该区间桶，而不是冒称某一个月的精确坐标；Tooltip和点击定位继续使用该桶的真实起止周期。当前范围主图不合并周期。
